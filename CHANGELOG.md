# Changelog

## 0.1.3

- Unify the bootstrap config file extension to `.treehole` across the phone apps and this plugin.
- Files exported by older app versions still import fine — the plugin reads pasted JSON text, not the filename.

## 0.1.0

- Initial release.
- Import encrypted diary emails over IMAP, decrypt them locally and merge them into Markdown notes.
- Support multiple accounts, bootstrap config import, photo attachments and optional auto sync.
